Planned Improvements
🖧
OPNsense → dedicated hardware. Currently a VM on Node 1 — any Node 1 maintenance or failure takes down routing for the entire network. Moving to a dedicated appliance eliminates this dependency entirely.
🌐
VLAN segmentation. Currently flat 192.168.1.0/24 — IoT devices, servers, and trusted clients share the same broadcast domain. Planning IoT, Servers, Trusted, and Management VLANs enforced at OPNsense.
🔍
Technitium DNS clustering. Single DNS instance on Node 1 today. Planning to cluster Technitium across both nodes — a DNS failure currently breaks name resolution for every service on the network.
